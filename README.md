# The Way of Christ

A Scripture-centered exploration of Christian discipleship, faith, and life through the teachings and example of Jesus Christ.

## Live site

**https://bip-river.github.io/thewayofchrist/**

The site is a single, self-contained web page ([`index.html`](index.html)) served
via GitHub Pages — no build step or external dependencies.

## Repository contents

| File | Purpose |
| --- | --- |
| [`index.html`](index.html) | The full "The Way of Christ" web page (GitHub Pages entry point) |
| [`LICENSE.md`](LICENSE.md) | Licensing terms (see below) |
| `.nojekyll` | Tells GitHub Pages to serve `index.html` as-is, without Jekyll processing |

## Publishing (GitHub Pages)

The page is published through GitHub Pages. To enable or update it:

**Settings → Pages → Build and deployment → Deploy from a branch**, then select
the `main` branch and the `/ (root)` folder.

Once enabled, the site is live at the URL above.
